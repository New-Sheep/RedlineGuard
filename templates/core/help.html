How to use RedlineGuard

A short path for in-house counsel. Not legal advice.

Words you will see

  • Playbook: your company’s written rules for routine contracts. Only changes when you Activate.
  • Activate: you confirm proposed rules become the live company checklist. Nothing is policy until then.
  • Memory: past Accept / Edit examples we reuse when drafting the next similar rewrite.
  • Override: mute one rule for now. Does not change the official playbook.
  • Security stop: upload halted because the file looks like it tries to hijack the AI. You can continue if you take responsibility.

Typical day

  1. Upload a contract (or try a quick demo).
  2. Open Review, work each issue with Accept / Edit / Reject.
  3. Check Memory and History.

No playbook yet?

Import a PDF or draft a starter from past contracts, review the proposed rules, then Activate.

If upload stops for security

If a file looks like it contains language meant to trick the AI, review stops. You can override and continue. You stay accountable.
